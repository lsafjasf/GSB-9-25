# vecpath — 矢量路径解析、裁剪与弧长参数化库

纯 Python 3 标准库实现，无第三方依赖。用于从矢量图形（SVG 路径数据）中提取
路径段序列，并计算**严格不低估**的包围盒与**带误差上界**的弧长，支持
**矩形裁剪**（输出可重新解析的指令序列）与**按弧长定位点**，服务于裁剪与布局。


## 功能与用法

```python
from vecpath import (
    parse, path_bbox, path_length,
    clip_path, to_path_data, point_at_length,
)

segs = parse("M 0 0 C 0 1 1 1 1 0 Q 2 -1 3 0 Z")  # 段序列 (绝对坐标)
box = path_bbox(segs)            # (minx, miny, maxx, maxy); 空路径返回 None
length, err = path_length(segs, tol=1e-6)  # (估值, 误差上界)

# 矩形裁剪: 返回仅含矩形内部片段的新段序列 (M/L/Q/C, 精确子段)
clipped = clip_path(segs, (0.25, -0.5, 2.0, 0.5))
d = to_path_data(clipped)        # 序列化为 SVG 路径数据, 可被 parse 重新解析
assert parse(d) == clipped

# 弧长参数化: 距起点弧长 s 处的点, err 为弧长误差上界
pt, err = point_at_length(segs, length / 2, tol=1e-6)
```

- 支持指令：`M/m L/l H/h V/v C/c S/s Q/q T/t Z/z`；`S/T` 平滑反射、
  隐式重复参数组、`m` 后隐式相对 `l`、紧凑数格式（`1-2`, `.5.25e1`）均已处理。
- 相对坐标在解析时立即累加为绝对坐标，连续相对指令累加正确（有专项测试）。
- `A/a`（圆弧）暂不支持，遇到即抛 `ValueError`，绝不静默出错。
- 所有段统一为 `Segment(kind, points)`：`M/L/Q/C/Z`，`Z` 即回到子路径起点的直线段。

## 包围盒：为什么不低估

对每段曲线在**解析意义下**求精确范围，而非采样或控制点近似：

- 直线/闭合段：两端点即范围。
- 二次贝塞尔：导数为一次函数，逐轴解 `(a0-a1) + (a0-2a1+a2)·t = 0`。
- 三次贝塞尔：导数为二次函数，逐轴解
  `(-a0+3a1-3a2+a3)·t² + 2(a0-2a1+a2)·t + (a1-a0) = 0`。

包围盒 = 端点 ∪ 所有 t∈(0,1) 极值点 的 min/max。贝塞尔曲线是关于 t 的连续
参数多项式，其在 [0,1] 上的最值必出现在端点或导数零点，因此该盒对真实曲线
是**精确的**（不是保守近似，也绝不低估）。唯一误差来源是浮点舍入，采样检验
用 1e-9 余量覆盖。

> 备选方案说明：控制点包围盒（`min/max` 全部控制点）因凸包性质必然包含曲线，
> 实现更简单但系统性偏大（本库测试中有断言：精确盒 ⊆ 控制点盒）。本库采用
> 可验证的精确方法，同时用采样检验兜底。

## 长度：细分逼近与误差上界

**算法**：对每段曲线递归二分（de Casteljau，t=0.5）。每片叶子有经典不等式

```
弦长 |P0Pn|  ≤  真实弧长 L  ≤  控制多边形长 Σ|PiP(i+1)|
```

（左：两点间直线最短；右：贝塞尔曲线是控制多边形的细分极限，每次细分
多边形长度单调不增地收敛到弧长。）当 `多边形长 - 弦长 ≤ tol` 时停止细分，
取估值 `(弦长 + 多边形长)/2`，该片误差 `≤ (多边形长 - 弦长)/2 ≤ tol/2`。
各叶子的误差界直接累加，与估值一同返回——**返回的 err 是严格上界而非启发式
估计**。细分深度上限 40，到达上限时该片仍按同一不等式给出有效界，保证终止。

二次贝塞尔先升阶为三次（`c1 = p0 + ⅔(p1-p0)`, `c2 = p2 + ⅔(p1-p2)`）复用同一
实现；直线/移动/闭合段长度精确、误差为 0。`tol` 为每段绝对容差，可配置。

**验证数据**（`python3 -m unittest discover -s tests`）：

| 用例 | 结果 |
|---|---|
| 直线 `M0 0 L3 4` | length = 5.0, err = 0（精确） |
| 16 段三次贝塞尔近似单位圆（真值 2π） | 估值与 2π 差 < 1e-5，报告界 < 1e-9 |
| 界自洽性：粗 tol 估值 ± 报告界 | 必覆盖细 tol（tol=1e-10）估值 |
| 细分单调性：tol 1e-3 → 1e-6 | 报告界严格减小 |

注：圆弧用例中"估值 vs 2π"的残差包含贝塞尔近似圆本身的几何误差
（16 段时 ~4e-7），与算法误差（< 报告界）是两个独立来源，测试中分别控制。

## 退化输入行为（均有测试）

| 输入 | 结果 |
|---|---|
| 空路径 `""` | 段列表 `[]`；bbox = `None`；长度 `(0.0, 0.0)` |
| 仅移动 `M 3 4` | bbox 退化为点盒 `(3,4,3,4)`；长度 0 |
| 零长度段（起终点相同，含曲线） | bbox 为点盒；长度 0，err 0 |
| 重复点 `L 5 0 L 5 0 L 5 0` | 正常计入，长度不累加 |
| 相对指令整体平移 | 同一相对路径不同起点：bbox 精确平移、长度不变 |


## 矩形裁剪：精确子段，不引入形状近似

**算法**：对每段求与矩形四边的交点参数——直线直接解线性方程，二次/三次
贝塞尔把单轴坐标（关于 t 的二次/三次多项式）等于边界值的方程解析求根
（三次方程用三角法/卡尔丹公式，再在原多项式上做 Newton 精化）。交点参数
把 [0,1] 切成小区间，逐区间取中点判定在矩形内则保留，保留部分用
de Casteljau 分割提取为**原曲线的精确子段**（不是折线近似）。因此：

- **长度单调**：裁剪后总弧长 ≤ 原路径总弧长（子段弧长之和不超过整段）；
- **包围盒关系**：裁剪后包围盒 ⊆ 裁剪矩形 ∩ 原包围盒（求根精度 ~1e-12，
  检验余量 1e-9·scale）；
- **可重解析**：`to_path_data` 用 repr 最短往返格式输出浮点，且只输出终点
  与控制点（起点由笔位隐含），`parse(to_path_data(segs)) == segs` 精确成立；
- 闭合段 `Z` 按回到子路径起点的直线参与裁剪，输出为 `L`；不衔接的片段
  之间自动插入 `M`。

## 弧长参数化：按弧长定位点

`point_at_length(segments, s, tol)` 先逐段累加带误差界的弧长定位目标段，
段内利用"部分弧长关于参数 t 单调不减"做二分（部分弧长 = de Casteljau
分割后左段的长度估值），直线段直接按比例。返回 `(point, err)`，其中
**err 是严格上界**：各段长度报告误差界之和 + 段内二分残差，即返回点的
真实弧长与 s 之差不超过 err。`s` 超出 `[0, 总长 ± 总长误差]` 时抛
`ValueError`。

## 性能数据

环境：Python 3.12.3，Linux x86-64。路径为 5000 段随机相对指令
（直线/三次/二次按 5:3:2 混合，字符串 153,442 字节），`scripts/benchmark.py` 实测：

| 阶段 | 5000 段 | 20000 段 |
|---|---|---|
| 解析 | ~20 ms | ~69 ms |
| 包围盒 | ~6 ms | ~23 ms |
| 长度 (tol=1e-4，报告界 ±6.7e-2) | ~1.34 s | — |
| 长度 (tol=1e-6，报告界 ±6.7e-4) | ~13.5 s | ~54 s |

解析与包围盒随段数线性扩展；长度耗时随精度要求增长（界收紧 100 倍约需
10 倍叶子数，符合误差 O(4^-深度) 的收敛率）。纯 Python 下单段长度开销
主要在递归细分，布局场景建议按需选择 tol（如 `1e-4` × 路径尺度）。
