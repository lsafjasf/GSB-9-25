# 自适应数值积分库（Python 3，仅标准库）

## 文件

- `adaptive_integrate.py` — 库源码
- `selftest.py` — 自测（对拍验证 + 未收敛用例 + 性能对比）

## 运行

```bash
python3 selftest.py    # 全部通过时退出码为 0，否则非 0
```

## 算法

- 每个子区间用 **Gauss-Kronrod 15 点**求积，内嵌 7 点 Gauss 结果之差作为误差估计；
  报告误差额外加上 `8·eps·max(1,|I|)` 的浮点舍入下界，保证机器噪声量级上
  “实际误差 ≤ 报告估计”仍可严格检验。
- 最大堆驱动的自适应二分：每步细分当前误差最大的子区间，
  收敛判据 `总误差 ≤ max(epsabs, epsrel·|总值|)`。
- 受限资源：`max_depth`（单区间最大二分深度）、`max_evals`（求值次数上限）。

## 设计决策（题目要求的明确说明）

- **端点奇性**：GK 为开公式，从不在端点求值，端点可积奇性可直接积；
  `endpoint_transform=True` 额外做 Kahaner 变换 `x = a+(b-a)t²(3-2t)`
  把节点压向端点，强奇性（如 `x^-1/2`）下求值次数从 >10⁵ 降到 45。
- **区间反序**：自动交换端点并对结果取负（不报错），`message` 中会注明。
- **无穷端点**：明确支持。`(a,∞)`、`(-∞,b)` 用 `x = a + t/(1-t)` 型替换，
  `(-∞,∞)` 用 `x = tan(π(t-1/2))`，均化为 `(0,1)` 上的有限积分。
- **未收敛**：触及 `max_depth` / `max_evals` 时返回 `Result(converged=False)`，
  含当前最优估计 `value`、不确定性 `error` 与区间 `result.interval`，
  绝不静默当作成功。
  `max_depth` 只冻结到顶的子区间（保留其贡献、不再细分），
  其余更浅的子区间继续压低误差；全部子区间到顶且误差仍超容差时才判未收敛。
  采样点返回非有限值（inf/nan）时同样走未收敛报告路径，
  不会因非有限值比较恒为假而误判“已收敛”。
- **振荡函数**：靠自适应细分处理（如 `cos(200x)`、`sin(1/x)`），
  无专用振荡算法；`sin(1/x)` 这类本征困难的函数会正确触发未收敛报告。

## 输出统计

`Result` 包含：`value`、`error`、`converged`、`neval`（函数求值次数）、
`nsub`（细分子区间数）、`elapsed`（耗时秒）、`message`、`interval`。

## 自测内容（`selftest.py`）

1. **解析对拍**：12 组解析可积函数（多项式/光滑/三角/有理/端点奇性×3/
   振荡/尖点/无穷×3），逐一验证 `|实际误差| ≤ 报告误差估计`。
2. **区间反序**：正反两向结果互为相反数。
3. **未收敛用例**：`sin(1/x)` + `max_depth=4`；`x^-1/2` + `max_evals=200`，
   均要求 `converged=False` 且返回的不确定性区间覆盖真值；
   采样点返回 `inf` 时必须 `converged=False`；
   尖点到顶冻结后其余子区间继续细分仍应收敛
   （`sin(100x) + 0.1|x-3.7|^0.5` + `max_depth=7`）。
4. **性能对比**：与固定均匀细分（GL4 + 倍增加密）对比求值次数与耗时，
   典型结果：近奇点 4.5×、端点奇性 >4×10⁴×（固定法在预算内不收敛）。
