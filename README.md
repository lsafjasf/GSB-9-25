# 简易正则匹配引擎（Python 3，仅标准库）

## 文件

| 文件 | 说明 |
|---|---|
| `regex_engine.py` | 引擎库：解析器 + Thompson NFA 编译 + Pike VM 模拟 |
| `test_regex.py` | 33 个单元自测（unittest） |
| `difftest.py` | 与 Python `re` 对拍 + 最小反例收缩 |
| `bench_pathological.py` | 病态模式 / 极长输入实测耗时 |

引擎本身不 import `re`；`re` 仅在对拍脚本中作为参照实现。

## 运行命令

```bash
python3 test_regex.py -v          # 单元自测
python3 difftest.py --n 50000     # 随机对拍（另含 n/5 组非法模式对拍）
python3 difftest.py --demo-shrink # 用故意写错的参照演示最小反例输出
python3 bench_pathological.py     # 病态模式耗时对比
```

库用法：

```python
import regex_engine as re2
re2.search(r"a*[bc]\d", "xxaaab7")   # -> (2, 6) ；无匹配返回 None
prog = re2.compile(r"^[a-z]+$")      # 预编译后反复使用
prog.search("hello")                 # -> (0, 5)
```

## 支持语法（与 `re.search` 语义对齐的子集）

- 字面字符；`.`（不匹配 `\n`）
- 字符类 `[...]` / 取反 `[^...]`：区间 `a-z`、`]` 居首为字面量、`-` 居首/尾为字面量、类内转义
- 量词 `*` `+` `?`（贪婪）
- 转义：`\d \D \w \W \s \S`、控制字符转义 `\a \f \n \r \t \v` 及标点转义（`\.` `\\` 等）
- 锚点 `^`（仅串首）、`$`（串尾或结尾换行符之前，与 `re` 一致）
- 空模式、空输入均合法

字符类短写与 `re` 的 str 语义一致（Unicode）：`\d` = 十进制数字（类别 Nd，
含阿拉伯-印度数字、全角数字等），`\w` = 字母数字或 `_`（含汉字等），
`\s` = Unicode 空白（含 `\xa0`、全角空格等）；大写形式为其补集。
字符类内 `\b` 为退格符（与 `re` 一致）；类外的 `\b` 是单词边界断言，
属子集外语法，报"未知转义"错误。

已知边界（有意为之）：连续量词（如 `a**`、`a*?`）一律报"连续量词"错误，
不支持分组/交替/懒惰量词等子集外语法。

## 语法错误：位置 + 原因，绝不静默按字面量处理

抛出 `RegexSyntaxError(pos, reason)`，覆盖：

| 模式 | 报错 |
|---|---|
| `[abc` | position 0: 未闭合字符类 |
| `abc\` | position 3: 悬空转义 |
| `*abc` | position 0: 量词缺少操作数 |
| `a**` | position 2: 连续量词 |
| `[z-a]` | position 3: 字符类区间反序 |
| `[a-\d]` / `[\d-a]` | 区间端点不能是转义类 |
| `a\e` | position 1: 未知转义 |

## 避免指数级搜索：方案选择与复杂度

**选择 Thompson NFA + Pike VM（状态机模拟），而非回溯+预算。**
理由：回溯预算只是"超时兜底"，超限时要么误报无匹配、要么行为依赖预算调参；
状态机模拟从算法上消除重复搜索——同一时刻最多 m 个活跃线程
（按 pc 去重，同 pc 只保留最高优先级线程），每个输入字符上做一次 O(m) 的
epsilon 闭包转移，耗时与模式结构无关，病态模式没有特例。

- 时间：**O(m·n)**，m = NFA 状态数（≤ 3×模式长度），n = 输入长度
- 空间：**O(m)**
- 匹配语义：线程按优先级排序，给出与回溯法一致的 leftmost-first（最左、贪婪）结果，
  因此对拍可以直接比较匹配区间而不仅是布尔结论。

读法：回溯法（re）在病态模式上随 n/k 指数爆炸，30 个字符的输入即超时；

（良性长输入上 re 更快是因为它是 C 实现；本引擎的价值是复杂度上界，
而非常数因子。）

## 对拍验证

`difftest.py` 按"双方语义一致的语法子集"随机生成模式（token 级）与输入，
比较引擎与 `re.search` 的**匹配区间**。生成器覆盖控制字符转义
（`\n` `\t` 等）与非 ASCII 语料（汉字、阿拉伯-印度数字、全角/不换行空白、
非 ASCII 类内区间等），因此 `\d \w \s` 的 Unicode 语义及其取反都能被
随机用例命中；另生成非法模式（未闭合类、悬空转义、缺操作数量词、反序区间、
未知转义）校验"双方都报错"。已验证：7 个种子共 35 万组随机
用例 + 7 万组非法模式用例，结论全部一致。

发现不一致时自动收缩（token 级删模式 → 子串级删输入 → 逐字符简化，
迭代到不动点），输出最小反例。演示（`--demo-shrink`，参照被故意改成
DOTALL 语义）：

```
==================================================
最小反例 (minimal counterexample):
  pattern: '.'
  input:   '\n'
  engine:  None
  re:      (0, 1)
==================================================
```

## 边界情形覆盖（`test_regex.py`）

- 空输入 / 空模式：`a*`→(0,0)、`^$`→(0,0)、`a`→None
- 锚点组合：`^$`、`^a*$`、`a$` 对 `"a\n"`（`$` 匹配结尾换行前）、模式中间的 `^`/`$`
- 字符类区间反序 `[z-a]`（报错）、重复/重叠区间 `[a-ca-cb-d]`（取并集）
- 控制字符转义 `\n \t \r \f \v \a`（类内类外）、类内 `\b` 退格符
- Unicode 字符类：`\d` 匹配阿拉伯-印度/全角数字、`\w` 匹配汉字、`\s` 匹配
  不换行/全角空格，及 `\D \W \S`、`[^\d]` 等取反形式
- 极长输入：100 万字符扫描、20 个 `a*` 链 + 5000 个 `a` 均限时内完成
