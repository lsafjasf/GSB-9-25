# Error message samples

Generated by `python3 examples/error_samples.py`.
Every error prints usage + `error: ...` to stderr and uses
exit code 2 (returned via `ParseError.exit_code` when
`exit_on_error=False`).

## Unknown long option (with suggestion)

    $ deploy --verbse web

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: unknown option: --verbse (did you mean --verbose?)
```

## Unknown short option

    $ deploy -z web

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: unknown option: -z
```

## Missing required value (end of argv)

    $ deploy web --env

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: option --env, -e NAME requires a value
```

## Missing value: next token looks like an option

    $ deploy --env --verbose web

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: option --env, -e NAME requires a value
```

## Invalid value type

    $ deploy --replicas two web

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: option --replicas, -r N: invalid int value: 'two'
```

## Boolean flag given a value

    $ deploy --verbose=yes web

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: option --verbose, -v does not take a value
```

## Missing required positional argument

    $ deploy --env prod

```
usage: deploy [OPTIONS] <service> [COMMAND]
error: missing required positional argument: service
```

## Unknown option inside a subcommand

    $ deploy rollback --step 2

```
usage: deploy rollback [OPTIONS]
error: unknown option: --step (did you mean --steps?)
```

## Missing subcommand (subcommand_required=True)

    $ tool

```
usage: tool [OPTIONS] COMMAND
error: missing subcommand (expected one of: run, stop)
```
